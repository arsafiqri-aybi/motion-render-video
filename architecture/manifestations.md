# Navigasi dari manifestasi

| Tampilan / gejala | Domain | Mulai dari |
|---|---|---|
| Pesan tidak tersampaikan | M01 M04 M15 M20 | Tulis message contract; periksa urutan informasi, hold, edit dan viewer comprehension. |
| Identitas terasa generik | M02 M05 M06 M07 M08 M12 | Bangun visual grammar serta motion grammar dari tujuan; nilai consistency dan distinction. |
| Teks bergerak tetapi sulit dibaca | M03 M06 M11 M12 M20 M21 | Pisahkan reveal dari reading window; inspect shaping, size, contrast dan exposure. |
| Gerak terasa mekanis atau tanpa berat | M10 M11 M12 M13 M16 | Periksa velocity/acceleration, pivot, deformation, response lag serta contact. |
| Ruang tidak terasa dalam | M03 M08 M09 M14 M18 | Uji projection, occlusion, parallax, light/shadow dan compositing cues. |
| Morph robek atau twist | M05 M10 M13 M21 | Periksa correspondence, winding, topology dan edge sampling. |
| Transisi terasa ditempel | M01 M12 M14 M15 M18 | Nyatakan fungsi perubahan konteks; compare match, cut dan motivated occlusion. |
| Efek flicker atau terlalu ramai | M04 M16 M17 M20 M21 | Pisahkan signal variation dari aliasing; batasi frequencies, hierarchy dan history. |
| Tepi transparan gelap | M07 M17 M18 M21 M22 | Uji premultiplication, filtering space dan output alpha support. |
| Suara tidak mengikuti impact | M11 M12 M19 M22 | Gunakan single cue timebase; decode dan ukur onset/duration serta listening. |
| Video bagus di preview tapi rusak setelah ekspor | M06 M07 M18 M21 M22 | Check actual codec, chroma, color transform/tags, timebase serta decoded pixels. |
| Video tidak nyaman ditonton | M04 M11 M14 M17 M19 M20 | Nilai whole-field movement, flash patterns, information load dan viewing conditions. |

[Master map](master-map.md) memberi jalur menuju setiap materi. Diagnosis tidak selalu tunggal; satu gejala dapat muncul dari beberapa mekanisme.
